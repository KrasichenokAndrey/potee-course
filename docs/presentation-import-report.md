## Манифест и повторяемый импорт

Манифест: docs/presentations-manifest.json. Для каждого PNG записаны полный абсолютный путь оригинала, полный абсолютный путь копии, переносимые пути относительно проекта, URL сайта, номер слайда, SHA-256, размер в байтах, ширина и высота. Манифест находится вне public и не включается в dist.

Повторный импорт проверен: 0 PNG перезаписано. Скрипт останавливается до импорта при неоднозначности номера, названия, порядка или наличии лишних целевых файлов. Оригиналы открываются только для чтения.

```text
node scripts/import-presentations.mjs --dry-run
node scripts/import-presentations.mjs
node scripts/validate-presentations.mjs --sources
node scripts/validate-content.mjs
node node_modules/astro/astro.js build
node node_modules/astro/astro.js preview --host 127.0.0.1 --port 4321
```
